## 수업 자료에서 반영한 관점

- 장애를 결핍이나 극복담으로만 말하지 않기.
- 장애 체험형 연출이 고정관념을 강화할 수 있음을 경계하기.
- 장애를 인간 다양성과 사회문화적 맥락 속에서 이해하기.
- 한 사람을 장애 범주로만 읽지 않고, 일상, 역할, 취향, 선택까지 함께 보기.

## 앱에 넣은 안전 경계

- 실제 대상자 본인이 아니라 인터뷰 기반 가상 사람책임을 표시.
- 확인되지 않은 개인정보, 진단명, 가족관계, 회사명, 학교명, 연락처를 생성하지 않도록 제한.
- 인터뷰 근거가 부족한 질문은 모른다고 말하고 확인된 주제로 연결.
- 도움에 대한 질문은 "먼저 어떻게 도울지 묻기"를 기본 태도로 답변.

## OpenAI API 설계 근거

- 브라우저에 API 키를 넣지 않고 `server.js`에서만 OpenAI API를 호출.
- 채팅: Responses API.
- 마이크 입력: Audio transcription API.
- 음성 답변: Audio speech API.
