# 트레일러 제작 계획

Steam 첫 트레일러는 실제 플레이 화면을 먼저 보여주는 60초 구성으로 잡는다.

## 기준

- Steam 첫 트레일러는 플레이어가 무엇을 하는 게임인지 빠르게 보여줘야 한다.
- 무음으로 봐도 흐름을 이해할 수 있어야 한다.
- 첫 번째 트레일러는 게임 플레이 중심으로 두고, HUD와 실제 상호작용 화면을 숨기지 않는다.
- Steam 권장 업로드 기준은 16:9, 최대 1920x1080, 30/60fps, 높은 비트레이트, MP4/H.264/AAC 조합이다.
- 공식 문서: https://partner.steamgames.com/doc/store/trailer

## 현재 산출물

- `TRAILER_SHOTLIST.tsv`: 60초 구성표
- `TRAILER_BUILD_CAPTURE_SHOTLIST.tsv`: 실제 빌드 스모크 캡처 기반 60초 구성표
- `TRAILER_CAPTIONS.srt`: 무음 시청용 SRT 자막 초안
- `TRAILER_CAPTIONS.vtt`: Steam/웹 검토용 WebVTT 자막 초안
- `trailer_animatic_60s.mp4`: 스크린샷 기반 60초 애니매틱. 낮은 실내 앰비언스 AAC 오디오를 포함한다.
- `trailer_build_capture_60s.mp4`: 현재 빌드가 직접 캡처한 화면 기반 60초 트레일러 후보. 샷별 미세 카메라 움직임, 조작 위치 표시, 낮은 실내 앰비언스 AAC 오디오를 포함한다.
- `Frames`: 애니매틱 생성용 프레임
- `BuildCaptureFrames`: 빌드 캡처 트레일러 생성용 프레임

## 60초 구성

| 시간 | 장면 | 목적 |
| --- | --- | --- |
| 0-3초 | 타이틀과 방 분위기 | 정서와 제목을 즉시 전달 |
| 3-10초 | 질문폰 | 첫 10초 안에 플레이어 행동이 질문 선택임을 보여줌 |
| 10-17초 | 장면 단서 | 오브젝트를 확인하고 묻는 구조 제시 |
| 17-28초 | 대화와 긴 답변 | 읽고 묻는 핵심 플레이 확인 |
| 28-37초 | 기억장 진행 | 여섯 장면 수집 구조 제시 |
| 37-46초 | 마무리 카드 | 세션의 도착점 제시 |
| 46-53초 | 기록함 | 기록으로 남는 가치 제시 |
| 53-57초 | 접근성 설정 | 판매용 품질 옵션 제시 |
| 57-60초 | 저장 데이터 안내와 제목 | 신뢰 요소와 제목으로 마무리 |

## 최종 편집 메모

- 애니매틱은 컷 순서와 자막 검토용이다.
- 빌드 캡처 후보는 현재 빌드의 실제 화면 상태와 플레이어 조작 흐름을 검토하기 위한 제출 전 후보이다.
- 최종본은 라이브 게임 녹화로 교체하고, 마우스 입력과 스크롤 움직임을 보여준다.
- 현재 배경음은 검토용 실내 톤이다. 최종본에서는 같은 방향의 더 자연스러운 믹스로 교체한다.
- 캡션은 기능명이 아니라 플레이어 행동 중심 문장으로 유지한다.
