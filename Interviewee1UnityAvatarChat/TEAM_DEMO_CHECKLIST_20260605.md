# 팀 시연 체크리스트

## 실행 전

- 메신저, API 키, 터미널 로그, 불필요한 파일 탐색기 창 닫기
- `RUN_AVATAR_CHAT.bat`로 실행
- 시작 화면에서 `처음부터` 선택
- 소리가 크면 설정에서 `소리 작게` 선택
- 서버 상태가 흔들리면 텍스트 입력 대신 추천 질문 중심으로 진행

## 보여줄 순서

1. 시작 화면
   - 제목 `겉!=속`
   - 목표: 먼저 보이는 단서를 고르고 질문으로 속 생활을 확인하는 구조

2. 첫 인상 선택
   - 목발, 책상, 표정 중 하나를 고르게 함
   - 정답 선택이 아니라 관찰의 출발점이라는 점 설명

3. 추천 질문 5개 진행
   - 같은 카테고리 안에서 추천 질문만 눌러 진행
   - 진행 표시가 `0/5`에서 `5/5`로 가는지 보여줌

4. 결과 카드
   - 질문 흐름과 대표 질답 확인
   - `다음 카테고리`와 `끝내기` 선택 설명

5. 다음 카테고리 이동
   - `다음 카테고리` 클릭
   - 다음 카테고리가 `0/5 질문`으로 시작되는지 확인

6. 기억장과 기록함
   - 열린 장면이 남는 구조 보여주기
   - 기록 저장은 시간이 있으면 마지막에만 시연

## 팀원에게 받을 질문

- 처음 화면에서 바로 무엇을 해야 할지 알겠나요?
- 5개 질문을 해야 결과 카드가 열린다는 규칙이 이해되나요?
- 추천 질문이 같은 카테고리 안에서만 나오는 게 자연스럽나요?
- 결과 카드가 한 세션의 마무리처럼 느껴지나요?
- 다음 카테고리로 넘어가는 흐름이 명확한가요?
- 기억장/기록함이 대화 결과물처럼 느껴지나요?
- 사운드가 분위기를 돕나요, 아니면 방해되나요?
- 일러스트가 각 카테고리와 잘 맞나요?

## 오늘 자동 확인한 항목

- 런처 사전 점검 통과
- 서버 문법 체크 통과
- 5문답 후 결과 카드/다음 카테고리 이동 확인
- 사운드 클립 준비와 소리 설정 확인
- 추천 질문 카드 겹침 없음
