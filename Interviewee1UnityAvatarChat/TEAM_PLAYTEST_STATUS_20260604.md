# 겉!=속 1차 프로토타입 현재 상태

작성일: 2026-06-05

## 지금 보여줄 수 있는 것

이 컴퓨터에서 팀원에게 1차 프로토타입을 보여줄 수 있는 상태입니다.

현재 들어간 핵심 흐름:

- 시작 화면과 첫 인상 선택
- 카테고리별 추천 질문
- 한 카테고리 안에서 5개 질문 진행
- 5문답 후 결과 카드 열기
- 결과 카드에서 다음 카테고리로 이동하거나 끝내기
- 기억장, 기록함, 의견 메모
- 결과 카드와 기억장에 연결된 일러스트
- 낮게 깔리는 배경음악과 버튼/질문/결과 카드 효과음
- 서버 연결 상태 확인과 준비 답변 fallback

## 오늘 확인한 것

- 실행 사전 점검 통과
  - 앱 실행 파일 확인됨
  - NodeRuntime `v22.22.3` 준비됨
  - 로컬 서버 실행 중
  - 채팅 모델 `gpt-5.4-mini` 준비됨
- 서버 문법 체크 통과
- 5문답 후 결과 카드와 다음 카테고리 이동 스모크 통과
- 사운드 기본/작게 설정 스모크 통과
- 추천 질문 겹침 레이아웃 PASS

## 이번 시연의 목적

이번에는 배포 테스트가 아니라, 이 컴퓨터에서 팀원이 직접 보고 흐름을 이해하는지 확인하는 단계입니다.

팀원에게 특히 봐 달라고 할 부분:

- 처음 화면에서 무엇을 해야 하는지 바로 알겠는지
- 첫 인상 선택이 작품 주제와 연결되는지
- 추천 질문만 눌러도 5문답 흐름이 자연스러운지
- 5개 질문 후 결과 카드가 한 세션의 마무리처럼 느껴지는지
- `다음 카테고리`와 `끝내기` 선택이 명확한지
- 기억장과 기록함이 "내가 나눈 대화가 남았다"는 느낌을 주는지
- 사운드가 분위기를 돕는지, 대사 읽기에 방해되는지

## 아직 부족한 점

- 다른 컴퓨터 배포용 ZIP은 아직 최신 상태로 다시 만들지 않았습니다.
- `Build/READY_TO_SEND`의 기존 ZIP은 2026-06-04 기준이고 이름에 `InternalWithApiKey`가 들어가므로 이번 시연 공유 파일로 쓰지 않습니다.
- 일부 내부 검토용 문구가 의견 메모 저장 파일에 남아 있습니다. 팀 내부 시연에는 괜찮지만 외부 공개 전에는 정리해야 합니다.
- 일러스트는 연결됐지만, `일상`, `독립`, `취미` 일부는 같은 계열 이미지를 공유하므로 카테고리별 차이가 충분한지 피드백이 필요합니다.
- 마이크 입력은 서버/API/장치 상태 영향을 받으므로 이번 1차 시연에서는 보조 기능으로만 보여줍니다.

## 시연 전 준비

1. 메신저, API 키, 터미널 로그처럼 보여줄 필요 없는 창을 닫습니다.
2. `RUN_AVATAR_CHAT.bat`로 실행합니다.
3. 시작 화면에서 `처음부터`로 깨끗하게 시작합니다.
4. 소리가 크면 설정에서 `소리 작게`로 바꿉니다.
5. 시연은 추천 질문 중심으로 진행하고, 마이크는 마지막에 선택적으로 보여줍니다.

## 한 줄 요약

지금은 이 컴퓨터에서 핵심 대화 흐름을 보여주기에 충분합니다. 팀원에게는 실행 배포보다 "처음 이해", "5문답 구조", "결과 카드 보상감", "사운드와 일러스트 분위기"를 중심으로 피드백을 받으면 됩니다.
