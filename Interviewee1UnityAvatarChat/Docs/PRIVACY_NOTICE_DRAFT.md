# 개인정보 및 저장 데이터 안내 초안

이 문서는 `겉!=속`를 유료 배포한다고 가정했을 때 플레이어에게 고지할 개인정보, 저장 데이터, 네트워크 동작을 정리한 초안이다. 최종 Steam 제출 전에는 배포 주체와 판매 지역 기준으로 별도 법무 검토가 필요하다. 배포 담당자는 `Docs/PRIVACY_NOTICE_FINAL_TEMPLATE.md`를 채워 `PRIVACY_NOTICE_FINAL.md`로 저장한 뒤 `EvidenceDrop/LegalSteam`에 넣어야 한다.

## 기본 원칙

- 이 게임은 실제 인터뷰 대상자의 초상이나 신원을 재현하지 않는다.
- 앱은 수업 인터뷰와 조별 활동 자료를 바탕으로 구성된 가상 사람책과 대화하는 형식이다.
- 자료에 없는 진단명, 회사명, 학교명, 주소, 연락처 같은 개인 정보는 새로 만들지 않는다.
- API 키는 앱 파일, 저장 기록, 피드백 파일, 배포 패키지에 저장하지 않는다.

## 로컬에 저장되는 데이터

| 항목 | 위치 | 목적 | 삭제 방법 |
| --- | --- | --- | --- |
| 이어하기 데이터 | Unity PlayerPrefs | 마지막 대화 진행도 복원 | 앱 정보 화면의 `저장 삭제` |
| 마무리 기록 | 사용자 데이터 폴더의 `EndingCards` | 선택한 문장과 오늘의 대화 보관 | 기록함의 `선택 삭제` 또는 정보 화면의 `저장 삭제` |
| 의견 메모 | 사용자 데이터 폴더의 `FeedbackNotes` | 플레이어 의견 보관 | 정보 화면의 `저장 삭제` |

마무리 기록과 의견 메모는 플레이어의 컴퓨터에 텍스트 파일로 남는다. 게임은 이 파일을 외부 서버로 자동 업로드하지 않는다.

## 네트워크와 API 동작

- 텍스트 대화는 로컬 서버가 실행 중이면 `Interviewee1CloneAI/server.js`의 `/api/chat`으로 요청한다.
- 설정에서 `로컬만`을 켜면 텍스트 질문은 서버로 보내지지 않고 Unity 내장 근거 답변만 사용한다.
- `OPENAI_API_KEY`가 없거나 API 호출이 실패하면 텍스트 대화는 Unity 내장 근거 답변으로 계속된다.
- 마이크 전사는 서버와 `OPENAI_API_KEY`가 있을 때만 동작하며, `로컬만`을 켜면 꺼진다.
- 마이크 녹음은 전사 요청을 보낼 때만 서버로 전달된다.
- 브라우저나 Unity 앱 안에 API 키를 입력하거나 저장하지 않는다.
- 개인정보, 내부 프롬프트, API 키, 의학·법률·복지 판단을 요구하는 질문은 서버에서 로컬 안전 답변으로 우회한다.

## 플레이어에게 보여줄 짧은 고지문

이 게임은 인터뷰 자료를 바탕으로 만든 가상 사람책과 대화하는 형식입니다. 마무리 기록과 의견 메모는 이 컴퓨터의 로컬 폴더에 저장되며, 정보 화면에서 직접 삭제할 수 있습니다. 설정에서 로컬 답변만 켜면 텍스트 질문은 서버로 보내지지 않습니다. 마이크 전사는 서버와 API 키가 있을 때만 동작하고, API 키는 앱 파일이나 기록 파일에 저장하지 않습니다.

## 출시 전 확인

- 상점 페이지에 로컬 저장과 마이크 전사 조건을 짧게 적는다.
- 정보 화면의 문구와 이 문서의 문구가 서로 다르지 않은지 확인한다.
- 배포 패키지 검증에서 API 키 형태 문자열이 발견되지 않아야 한다.
- `RunSafetyQA.ps1`에서 개인정보·프롬프트 주입·의학/법률 판단 질문이 안전 답변으로 처리되어야 한다.
- 실제 판매 전에는 `PRIVACY_NOTICE_FINAL_TEMPLATE.md`의 배포 주체, 문의 채널, 판매 지역, 마지막 업데이트 날짜를 채워 최종 문서로 확정한다.
