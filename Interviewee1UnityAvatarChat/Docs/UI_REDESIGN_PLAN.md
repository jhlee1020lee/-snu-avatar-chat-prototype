# 대상자1 아바타 인터뷰 UI 재기획서

작성일: 2026-05-21

## 한 줄 방향

지금 화면은 정보 패널을 나열한 앱처럼 보인다. 다음 버전은 `책상 앞에서 인터뷰하는 장면`을 첫인상으로 만들고, 질문 선택과 근거 확인은 장면 위에 얹힌 작은 도구처럼 보이게 한다.

## 현재 UI 진단

기준 화면: `Build/smoke-ui-v2-final4.png`

현재 문제는 색 하나나 버튼 하나의 문제가 아니라 구조 문제다.

- 큰 직사각형이 너무 많다. 상단 제목 박스, 하단 대사 박스, 오른쪽 패널, 챕터 버튼, 질문 버튼, 기능 버튼이 전부 네모라서 시각적 위계가 죽는다.
- 오른쪽 패널이 실제 대화보다 더 강하게 보인다. 관람자는 캐릭터와 대화하는 느낌보다 설문/관리 화면을 보는 느낌을 받는다.
- 장면 속 사물 핫스팟은 좋은 방향이지만, 현재 `+` 버튼도 사각형이라 배경 위에 붙은 UI 스티커처럼 보인다.
- 대사창이 화면 하단을 크게 덮는다. 긴 글 스크롤 문제는 해결됐지만, 현재 형태는 비주얼노벨 대사창이라기보다 반투명 검은 입력 폼에 가깝다.
- 선택지는 오른쪽에 갇혀 있어 장면과 연결되지 않는다. 책상, 컵, 메모, 이동 같은 소재가 배경에 있는데도 질문 흐름은 별도 패널에서만 읽힌다.
- `챕터와 후속 질문`이라는 말이 기능 설명처럼 보인다. 관람자가 지금 무엇을 해야 하는지보다 시스템 구조가 먼저 보인다.

## 새 UI 콘셉트

### 콘셉트 이름

`책상 위 인터뷰 노트`

화면을 앱 패널로 나누지 않는다. 관람자가 책상 맞은편에 앉아 있고, 질문은 책상 위 노트/쪽지/사물에서 꺼내 보는 구조로 만든다.

### 핵심 원칙

1. 장면이 먼저 보인다.
2. UI는 장면 위에 붙은 네모 박스가 아니라 장면 속 도구처럼 보인다.
3. 오른쪽 고정 패널을 없애거나 접힌 노트 형태로 줄인다.
4. 질문 선택은 큰 직사각형 목록이 아니라 말풍선, 쪽지, 탭, 원형 사물 핫스팟으로 분산한다.
5. 긴 답변은 화면 밖으로 나가지 않되, 기본 노출은 2~3줄 중심으로 한다.
6. 근거와 지난 대화는 항상 보이지 않아도 된다. 필요할 때 여는 `자료 서랍`으로 바꾼다.
7. 모든 조작은 관람자가 3초 안에 이해해야 한다.

## 화면 구조 제안

### 1. 기본 대화 화면

구성:

- 배경: 밝은 연구실/책상 장면 전체 화면 유지
- 캐릭터: 중앙에서 약간 오른쪽, 현재보다 배경과 더 자연스럽게 맞춤
- 대사창: 하단 전체 박스가 아니라 낮은 반투명 곡선형 대화 띠
- 이름표: 왼쪽 위 사각 라벨 대신 대사창에 붙은 작은 탭
- 입력: 대사창 아래 고정 흰 박스 대신 `질문하기` pill 버튼을 누르면 열리는 짧은 입력줄
- 후속 질문: 대사창 위 또는 캐릭터 옆에 2~3개의 말풍선 칩으로 잠깐 표시
- 근거/지난 대화: 오른쪽 고정 패널 대신 접힌 노트 아이콘

레이아웃 스케치:

```text
┌──────────────────────────────────────────────────────────────┐
│  작은 제목 리본                                  노트 아이콘  │
│                                                              │
│            배경 오브젝트 핫스팟     캐릭터                  │
│                  ○       ○                                  │
│                                                              │
│          질문 칩 1     질문 칩 2     질문 칩 3               │
│                                                              │
│     ╭──────────────────────────────────────────────╮         │
│     │ 답변 탭  대사 2~3줄, 길면 내부 스크롤        │         │
│     ╰──────────────────────────────────────────────╯         │
│       질문하기        녹음        보내기                      │
└──────────────────────────────────────────────────────────────┘
```

### 2. 질문 선택 방식

현재:

- 오른쪽에 챕터 6개
- 오른쪽에 후속 질문 3개
- 오른쪽에 더 듣기/근거/마무리

변경:

- 챕터는 항상 보이는 버튼이 아니라 `질문 노트` 안의 탭으로 이동
- 기본 화면에는 현재 답변과 관련된 후속 질문 3개만 말풍선 칩으로 표시
- 사물 핫스팟은 사각 `+`가 아니라 작은 원형 빛점과 얇은 선으로 표시
- 핫스팟에 마우스를 올리면 짧은 라벨만 나온다
- 클릭하면 바로 질문하지 않고, 작은 미리보기 쪽지가 떠서 `묻기`를 누르게 한다

### 3. 오른쪽 패널 대체

오른쪽 패널은 가장 먼저 없애야 할 대상이다. 현재 UI가 네모 박스처럼 보이는 가장 큰 원인이다.

대안:

- 기본 상태: 오른쪽 위에 작은 `노트` 아이콘 하나만 표시
- 클릭 상태: 화면 오른쪽에서 종이 노트가 360px 정도 밀려 나온다
- 노트 안 탭: `질문`, `근거`, `기록`
- 노트는 완전한 사각 패널이 아니라 종이 질감, 상단 클립, 탭 모양을 사용한다
- 노트가 열려도 캐릭터와 대사창을 완전히 덮지 않는다

### 4. 하단 대사창

현재 검은 직사각형 대사창은 기능적으로는 맞지만 분위기를 죽인다.

변경:

- 높이: 현재보다 20~25% 낮춤
- 형태: 양 끝을 살짝 둥글게 하거나, 상단 가장자리를 아주 약한 곡선/그라데이션으로 처리
- 색: 완전 검정 대신 따뜻한 잉크색 `#1F2328` 70~78% 투명
- 텍스트: 2~3줄 기본, 긴 답변은 내부 스크롤
- 스크롤바: 항상 보이지 않게 하고, 긴 답변일 때만 얇은 청록 선 표시
- 입력창: 항상 큰 흰 박스로 두지 말고 `직접 묻기` 버튼을 누르면 대사창 아래에서 부드럽게 열린다

### 5. 타이틀과 상태 표시

현재 상단 제목 박스도 네모 느낌을 강화한다.

변경:

- 상단 왼쪽 제목 박스 제거
- 제목은 장면 위에 작은 리본 텍스트로만 표시
- 상태 문구는 오른쪽 위 작은 텍스트로 유지하되, 평소에는 숨김 또는 흐리게 처리
- `챕터와 후속 질문` 같은 시스템 문구는 제거

새 문구:

- 제목: `책상 맞은편 인터뷰`
- 부제: `일상, 이동, 도움, 공부를 묻는 대화`
- 노트 버튼: `질문 노트`
- 근거 탭: `근거`
- 기록 탭: `지난 말`

## 컴포넌트 설계

### 사물 핫스팟

형태:

- 26~32px 원형 점
- 배경색: 청록/민트 계열, 55~70% 투명
- 외곽에 1초 주기의 약한 pulse
- `+` 문자는 제거하거나 아주 작게 둔다
- hover 시 짧은 쪽지 라벨 표시

사물별 연결:

- 노트북: 일과 공부
- 컵/조명: 휴식과 취미
- 게시판 메모: 자기이해
- 창문/문: 이동과 접근성
- 책상: 평범한 하루
- 의자/가방: 도움을 조율하는 방식

### 질문 칩

형태:

- 말풍선 또는 쪽지 조각
- 완전 사각형 금지
- 한 줄 18~28자 내외
- 3개까지만 노출
- hover 시 살짝 위로 뜨고 색만 변함

색:

- 일상: 따뜻한 종이색
- 이동: 연한 하늘색
- 도움: 부드러운 민트색
- 일과 공부: 차분한 남색
- 독립: 연한 보라가 아닌 회보라
- 취미: 연한 살구색

### 질문 노트

형태:

- 오른쪽 슬라이드 노트
- 탭 3개: 질문, 근거, 기록
- 종이 질감 배경
- 탭은 사각 버튼이 아니라 책갈피처럼 보이게 한다

기능:

- 질문 탭: 챕터별 질문을 접어서 보여줌
- 근거 탭: 답변 근거 2~3개를 짧게 표시
- 기록 탭: 최근 대화만 요약

### 대사창

형태:

- 낮은 반투명 dialogue band
- 이름표는 좌측 상단 작은 탭
- 긴 답변만 스크롤
- 화면 아래 입력창과 시각적으로 분리

금지:

- 대사창 내부에 또 다른 카드 넣기
- 버튼을 대사창 안에 여러 개 넣기
- 대사 텍스트가 캐릭터 얼굴이나 손을 가리기

## 구현 단계

### 1단계: 네모 박스 줄이기

- 오른쪽 고정 패널 제거
- `질문 노트` 접힘/펼침 상태 추가
- 챕터 버튼을 노트 안으로 이동
- 기본 화면에는 후속 질문 칩 3개만 노출

### 2단계: 형태 바꾸기

- 사각 핫스팟을 원형 pulse 핫스팟으로 변경
- 질문 버튼을 말풍선/쪽지 칩으로 변경
- 하단 대사창을 낮은 dialogue band로 변경
- 상단 제목 박스를 작은 리본으로 축소

### 3단계: 장면과 연결하기

- 노트북, 컵, 메모, 창문, 책상 등 사물별 질문 미리보기 추가
- hover 시 사물과 질문 쪽지를 얇은 선으로 연결
- 근거는 오른쪽 패널 상시 노출이 아니라 노트 탭으로 이동

### 4단계: 검수와 조정

- 1920x1080 기본 캡처
- 긴 답변 캡처
- 질문 노트 열린 상태 캡처
- 입력창 열린 상태 캡처
- 1366x768 축소 캡처
- 텍스트 겹침, 캐릭터 가림, 사각 박스 과다 여부 확인

## 검수 기준

UI가 좋아졌다고 판단하려면 아래를 모두 만족해야 한다.

- 첫 화면에서 가장 먼저 보이는 것은 패널이 아니라 캐릭터와 책상 장면이어야 한다.
- 화면에 항상 보이는 큰 직사각형 패널은 하단 대사창 하나 이하로 줄인다.
- 오른쪽에는 고정 패널이 아니라 접힌 노트 아이콘만 보여야 한다.
- 후속 질문은 큰 목록 버튼이 아니라 말풍선/쪽지형 칩이어야 한다.
- 사물 핫스팟은 사각 `+` 박스가 아니라 원형 또는 빛점 형태여야 한다.
- 긴 답변은 화면 아래를 뚫지 않고 대사창 내부에서만 스크롤되어야 한다.
- 근거와 지난 대화는 필요할 때 열 수 있지만, 기본 화면을 차지하지 않아야 한다.
- 모든 버튼 텍스트는 한 줄 또는 안정적인 두 줄 안에 들어와야 한다.
- UI 색은 청록/남색/종이색만 반복되는 단조로운 팔레트가 아니라, 장면 색과 어울리는 보조색을 가져야 한다.
- 스크린샷을 봤을 때 설문지나 관리자 패널이 아니라 대화형 인터뷰 장면으로 읽혀야 한다.

## 이번 재기획의 결론

현재 UI를 조금 둥글게 하거나 색만 바꾸는 정도로는 해결되지 않는다. 핵심은 오른쪽 고정 패널과 반복 사각 버튼을 걷어내고, 질문/근거/기록을 `책상 위 인터뷰 노트`라는 장면 속 도구로 다시 설계하는 것이다. 구현은 기존 기능을 버리는 것이 아니라, 같은 기능을 장면 중심 형태로 다시 배치하는 쪽으로 가야 한다.
