## 사람이 한 번 더 판단하면 좋은 항목 (변경 보류)

1. **전기적(傳記的) 답변의 보고체 ↔ 1인칭 혼용**
   - `persona.json`의 `self-understanding`("…불안이 컸다고 했어요 / 정리됩니다 / 생겼다고 했습니다")와 `accessibility`("…있었다고 했지만 / 봤습니다 / 답했다고 …") 답변은 다른 답변의 일관된 1인칭과 달리 3인칭 보고체가 섞여 있습니다.
   - `voiceStyle.firstPerson`(자연스러운 1인칭)와는 어긋나 보이지만, 이는 "실제 본인이 아니라 자료 기반 대화"(`makeAuthenticityReply`)라는 안전·진정성 경계를 위해 **의도적으로 거리를 둔 표현**일 가능성이 큽니다. 톤 통일을 위해 1인칭으로 바꾸면 사실 주장 강도가 달라질 수 있어 보류했습니다. 조원 확인 후 결정 권장.

2. **표기 정규화 `그 다음` → `그다음`**
   - `server.js:671`, `persona.json:88`(crutch), `AvatarChatApp.cs:6044`, `:11990`에 `그 다음` 표기가 있습니다. 표준국어대사전 표제어는 `그다음`(붙여 씀)이지만, `그 다음`도 널리 통용되어 오류는 아닙니다. 불필요한 표기 변경(churn) 회피를 위해 보류했습니다. 일괄 통일을 원하면 4곳 동시 적용 가능.

3. **경미한 중복 표현(보류)**
   - `persona.json`의 `직장과 관계` 답변 "…상대도 이해하고 납득하고 원활하게…"는 `이해/납득`이 의미가 겹치고 `-고` 연결이 셋 이어집니다. 강조 의도일 수 있어 보류. 다듬는다면 "…상대도 이해하고 원활하게 같이 일할 수 있습니다." 정도.
