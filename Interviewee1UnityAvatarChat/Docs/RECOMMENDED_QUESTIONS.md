# 추천 질문 및 답변 보강 목록

이 문서는 게임 화면의 추천 질문 버튼에 표시될 수 있는 질문 후보와, 추천 질문 답변을 두껍게 만들기 위해 보강한 서버 기준을 정리한 것이다.

적용 규칙:
- 버튼은 한 번에 3개만 표시한다.
- 이미 사용자가 물어본 질문과 같은 문장은 다시 표시하지 않는다.
- 서버가 추천 질문을 주면 서버 후보를 먼저 쓰고, 부족하면 Unity 후보로 채운다.
- 서버가 비정상이면 질문 진행 자체가 막히므로 내장 답변용 추천 질문으로 이어가지 않는다.
- 추천 질문 답변은 장면 설명, 생활에서의 의미, 다른 전시 장면과의 연결을 함께 담는다.
- 개인정보, 병명, 진단명, 장애 등급, 치료 이력, 회사명, 학교명, 주소, 가족사, 돈, 생활비/공과금 세부 금액, 연봉, 월급은 묻지 않는다.

## 답변 보강 기준

서버 답변 프롬프트와 `persona.json` 근거 카드를 함께 보강했다.

- 추천 질문이나 장면형 질문은 2문단, 5~8문장, 500~800자 안팎으로 답한다.
- 단순 인사나 범위 밖 질문만 짧게 답한다.
- 근거 카드 답변은 잘리지 않도록 대부분 2문단 안에 핵심 근거를 재배치했다.
- `목발` 답변은 몸 상태, 길 상태, 입구, 엘리베이터, 돌아오는 길까지 연결한다.
- `자취방` 답변은 집안일, 생활비, 공과금, 시간 관리, 직접 정하는 감각을 포함하되 구체 금액은 묻거나 만들지 않는다.
- `책상과 일` 답변은 직장 업무, 박사과정 공부, 노트북, 메모, 결과물까지 연결한다.
- `도움` 답변은 먼저 묻기, 잠깐 기다리기, 설명할 시간, 혼자 할 수 있는 부분 존중을 포함한다.
- `직장과 관계` 답변은 필요한 도움을 먼저 설명하는 방식, 조율, 결과물로 기여하는 장면을 포함한다.
- `접근성` 답변은 미국/한국 비교, 대중교통 정보, 지원 서비스, 전동휠체어 대여 경험을 2문단 안에 담는다.
- `자기이해` 답변은 민폐 불안, 스스로 설명하는 태도, 자취와 독립 경험을 함께 담는다.
- `평범함` 답변은 목발에서 책상, 방, 취미, 관계로 시선이 이동해야 한다는 전시 관점을 포함한다.

## 서버 동적 생성 규칙

서버에서 `OPENAI_SUGGESTIONS`를 켠 경우에는 고정 템플릿 대신 새 문장을 생성할 수 있다. 이때도 아래 규칙을 따른다.

- 정확히 3개를 만든다.
- 모두 같은 주제의 후속 질문으로 만들지 않는다.
- 1개는 방금 답변을 한 단계 깊게 묻는다.
- 1개는 다른 생활 장면으로 넘어간다.
- 1개는 관점, 도움 방식, 전시 의미를 넓힌다.
- 직전 질문과 이미 물어본 질문은 반복하지 않는다.
- 추상적인 “더 들려주세요”, “어떤 의미인가요”류 질문은 피한다.
- 개인정보, 병명, 회사명, 학교명, 연락처, 주소, 가족사, 돈, 생활비/공과금 세부 금액, 연봉, 치료 이력은 묻지 않는다.
