## 수집하거나 저장하는 데이터

`겉!=속`는 실제 인터뷰 대상자의 초상, 신원, 연락처, 주소, 학교명, 회사명, 진단명 같은 개인정보를 새로 만들거나 저장하지 않는다. 게임 진행을 위해 아래 데이터만 플레이어의 로컬 컴퓨터에 저장한다.

| 항목 | 저장 위치 | 목적 | 삭제 방법 |
| --- | --- | --- | --- |
| 이어하기 데이터 | Unity PlayerPrefs | 마지막 대화 진행도 복원 | 앱 정보 화면의 `저장 삭제` |
| 마무리 기록 | 사용자 데이터 폴더의 `EndingCards` | 플레이어가 선택한 마무리 문장 보관 | 기록함의 `선택 삭제` 또는 정보 화면의 `저장 삭제` |
| 의견 메모 | 사용자 데이터 폴더의 `FeedbackNotes` | 플레이어가 남긴 의견 보관 | 정보 화면의 `저장 삭제` |

이 데이터는 기본적으로 플레이어의 로컬 컴퓨터에만 남으며, 게임은 마무리 기록이나 의견 메모를 외부 서버로 자동 업로드하지 않는다.

## 네트워크와 마이크 전사

- 텍스트 대화는 로컬 대화 서버가 실행 중일 때만 로컬 서버의 `/api/chat`으로 전송된다.
- 설정에서 `로컬만`을 켜면 텍스트 질문은 서버로 보내지지 않고 앱 내장 근거 답변만 사용한다.
- `OPENAI_API_KEY`가 없거나 API 호출이 실패하면 텍스트 대화는 앱 내장 근거 답변으로 계속된다.
- 마이크 전사는 로컬 서버와 `OPENAI_API_KEY`가 모두 있을 때만 동작하며, `로컬만`을 켜면 비활성화된다.
- 마이크 녹음은 전사 요청을 처리할 때만 서버로 전달된다.
- 브라우저나 Unity 앱 안에 API 키를 입력하거나 저장하지 않는다.
- API 키는 앱 파일, 저장 기록, 피드백 파일, 지원 번들, 배포 패키지에 저장하지 않는다.

## 안전 처리

개인정보, 내부 프롬프트, API 키, 의학·법률·복지 판단을 요구하는 질문은 서버에서 로컬 안전 답변으로 우회한다. 플레이어가 기록 삭제를 요청하면 앱 안의 정보 화면에서 `저장 삭제`를 실행하도록 안내한다.

## Steam 상점용 짧은 고지문

이 게임은 인터뷰 자료를 바탕으로 만든 가상 사람책과 대화하는 형식입니다. 마무리 기록과 의견 메모는 이 컴퓨터의 로컬 폴더에 저장되며, 정보 화면에서 직접 삭제할 수 있습니다. 설정에서 로컬 답변만 켜면 텍스트 질문은 서버로 보내지지 않습니다. 마이크 전사는 서버와 API 키가 있을 때만 동작하고, API 키는 앱 파일이나 기록 파일에 저장하지 않습니다.
