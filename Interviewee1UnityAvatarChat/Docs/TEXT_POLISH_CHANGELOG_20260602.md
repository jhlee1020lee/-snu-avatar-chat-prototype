# 겉!=속 텍스트 다듬기 정리

- 작업일: 2026-06-02
- 범위: 인게임 문구, 답변 데이터, 상점 문구, 플레이테스트 안내, 설치 패키지 안내
- 목표: 번역투와 AI 설명문 느낌을 줄이고, 실제 플레이어가 읽는 문장처럼 짧고 자연스럽게 정리

## 전체 방향

- 긴 설명문을 줄이고, 화면 문구는 짧은 명령형/상태형으로 정리했다.
- "보상", "선택 결과", "품질 근거", "긍정 평가"처럼 운영자나 시스템 로그처럼 보이는 표현을 플레이어용 표현으로 바꿨다.
- 답변 문장은 "설명합니다"보다 "말하듯 이어지는 문장"에 가깝게 줄였다.
- 게임명은 계속 `겉!=속` 기준으로 유지했다.
- Unity 실행 없이 정적 문구와 패키지 문서만 수정했다.

## 첫 인상 흐름

첫 인상 선택 후 나오는 문장을 다듬었다.

- `목발`: 이동, 일상, 도움 방식으로 자연스럽게 이어지도록 수정
- `책상`: 일과 공부, 이동, 도움, 쉬는 시간을 한 장면 안에서 보도록 수정
- `표정`: 표정이 일, 이동, 취미와 같은 하루 안에 놓인다는 흐름으로 수정

대표 질문도 바꿨다.

- `목발은 하루의 이동과 어떻게 이어지나요?`
- `책상은 일과 공부, 이동의 리듬과 어떻게 이어지나요?`
- `표정 뒤의 평범한 하루는 어떤 장면으로 이어지나요?`

## 답변 톤

수정 파일:

- `Assets/Scripts/AvatarChatApp.cs`
- `../Interviewee1CloneAI/data/persona.json`

내장 답변과 서버 답변 데이터의 톤을 맞췄다.

대표 방향:

- "이것은 ~에 가깝습니다" 같은 설명문을 줄임
- "중요합니다" 같은 평가 문장을 줄이고, 장면 자체를 보여 주는 문장으로 변경
- "AI가 설명하는 느낌"보다 "인터뷰 기록을 바탕으로 차분히 말하는 느낌"에 맞춤
- 목발, 자취방, 도움, 처음 가는 장소, 책상, 취미, 평범함 관련 답변을 보정

## 플레이테스트 안내

수정 파일:

- `Docs/PLAYTEST_PARTICIPANT_BRIEF.md`
- `Docs/PLAYTEST_MODERATOR_SCRIPT.md`

- 첫 문장을 운영 문서 느낌에서 실제 안내문 느낌으로 변경
- "품질 검토"보다 "문제를 확인하고 다음 버전을 고치는 데 사용"처럼 쉽게 설명
- "문장이 AI처럼 느껴지는 순간"을 "문장이 사람 말처럼 들리지 않는 순간"으로 변경
- "유료 게임으로 보기에는 부족한 점"을 "돈을 내고 하기에는 부족하다고 느낀 점"으로 변경

진행자 스크립트:

- 읽어 줄 문장을 더 자연스럽게 정리
- "AI 설명문 느낌"을 "설명문을 읽는 느낌"으로 바꿈
- "5달러 이상 유료 게임" 같은 내부 평가 표현을 "돈을 내고 플레이한다면"으로 완화
