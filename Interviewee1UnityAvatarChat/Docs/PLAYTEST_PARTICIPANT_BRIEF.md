# 플레이테스트 참가자 안내문

세션을 시작하기 전에 읽는 짧은 안내문입니다.

## 오늘 할 일

`겉!=속`를 처음 보는 상태로 플레이합니다.

진행자는 처음부터 조작법을 자세히 설명하지 않습니다. 어디서 막히고 무엇을 자연스럽게 이해하는지 보기 위한 테스트입니다.

## 진행 시간

- 예상 시간: 20-30분
- 최소 목표: 질문과 답변 5회 이상
- 마지막에 저장, 기록 확인, 의견 남기기까지 진행합니다.

## 입력하지 말아야 할 내용

- 실제 비밀번호
- 계정 정보
- 주민등록번호, 전화번호, 주소
- 민감한 건강 정보
- 결제 정보
- API 키나 인증 코드

질문이 개인적인 내용을 요구한다고 느껴지면 가상의 예시로 바꿔 입력해도 됩니다.

## 남는 자료

테스트 뒤에는 다음 자료가 저장될 수 있습니다.

- 게임 안에서 남긴 의견
- 빌드 ID와 실행 환경 정보
- 진행자가 작성한 관찰 기록
- 문제 화면의 스크린샷 또는 녹화 파일

자료는 문제를 확인하고 다음 버전을 고치는 데 사용합니다. 이름 대신 참가자 코드로 기록합니다.

## 테스트 중 말해 주면 좋은 것

- 무엇을 해야 할지 모르겠는 순간
- 문장이 사람 말처럼 들리지 않는 순간
- 답변이 너무 길거나 읽기 어려운 순간
- 버튼이나 메뉴를 찾기 어려운 순간
- 저장 기록이나 삭제 안내가 불안한 순간
- 돈을 내고 하기에는 부족하다고 느낀 점

## 중단

불편하면 언제든 중단할 수 있습니다. 중단해도 실패가 아닙니다. 중단한 이유도 중요한 의견으로 기록됩니다.
